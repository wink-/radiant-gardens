# Radiant Gardens Docs

Radiant Gardens is an Astro-based marketing site and business-planning repo for a Finger Lakes food-garden design and installation service, currently in planning.

## Source Files

- `src/pages/` contains the public Astro pages; `src/layouts/` and `src/components/` hold the shared shell and botanical SVG components.
- `radiant-gardens-business-plan.md` and `updated-business-plan.md` contain business-plan source material (reference only — see the content boundary in [notes.md](notes.md)).
